# ميزة تتبع الطرود (DHD)

البوت يكتشف أي رقم تتبع في المجموعة (مثل DHDCQI726101420522909) ويجيب بمرحلة الطلبية.

## مهم: خطوة التحقق (مرة وحدة)
طريقة طلب موقع platform.dhd-dz.com/suivi ما قدرتش نختبرها (الموقع يحجب الاتصال الآلي).
1. افتح الموقع في المتصفح > F12 > تبويب Network > اكتب رقم تتبع حقيقي.
2. شوف الطلب اللي يخرج (Fetch/XHR) وانسخ رابطه (وطريقته GET أو POST).
3. ضيف في GitHub Secrets/Variables:
   - GET:  DHD_TRACK_URL = https://.../{n}   (حط {n} مكان الرقم)
   - POST: DHD_TRACK_POST_URL و DHD_TRACK_FIELD (اسم الحقل)
4. جرب: `python tracking.py DHDCQI726101420522909` — يطبع الرد الخام.
ولازم تضيف المتغيرات في bot.yml داخل env (راجع الملف).
