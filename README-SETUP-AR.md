# إعداد Mayna Groupe Bot

## GitHub Actions Secrets
من المستودع افتح Settings → Secrets and variables → Actions → New repository secret، وأضف:

- `TELEGRAM_BOT_TOKEN`: توكن البوت من BotFather.
- `GROUP_CHAT_ID`: رقم مجموعة MaynaGroup ويكون غالبًا سالبًا ويبدأ بـ `-100`.
- `ADMIN_CHAT_ID`: رقم محادثة المشرف الشخصية، إذا أردت إرسال تنبيهات له أيضًا.
- `GEMINI_API_KEY`: مفتاح Gemini؛ اختياري، لكن يساعد على فهم الأسئلة المصاغة بطرق مختلفة.

بعد إضافة الأسرار، افتح Actions وشغّل workflow يدويًا من Run workflow. تأكد أن البوت موجود في المجموعة والقناة، وأنه يستطيع إرسال الرسائل ونسخ منشورات القناة.

## حدود مهمة
البوت يستطيع نسخ المنشورات المعرّفة حاليًا داخل `VIDEOS` فقط. لا يستطيع بوت Telegram تحميل تاريخ القناة القديم كاملًا تلقائيًا. لاستعمال كل منشورات القناة، يلزم تصدير منشورات القناة من Telegram Desktop ثم إضافة آلية استيراد/فهرسة لهذا التصدير. منشورات القناة الجديدة التي تصل للبوت تُسجّل في سجل التشغيل فقط في النسخة الحالية ولا تُحفظ في قاعدة بيانات دائمة.

إذا لم تتطابق صيغة السؤال مع الكلمات المعروفة، يحاول Gemini اختيار موضوع من المواضيع المدعومة. إذا تعذّر تحديد موضوع، يُحوّل السؤال للمشرفين بدل تخمين الإجابة. Gemini اختياري؛ من دونه تبقى المطابقة النصية شغّالة.
