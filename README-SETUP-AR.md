# إعداد Mayna Groupe Bot

## GitHub Actions Secrets
من المستودع افتح Settings → Secrets and variables → Actions → New repository secret، وأضف:

- `TELEGRAM_BOT_TOKEN`: توكن البوت من BotFather.
- `GROUP_CHAT_ID`: رقم مجموعة MaynaGroup ويكون غالبًا سالبًا ويبدأ بـ `-100`.
- `ADMIN_CHAT_ID`: رقم محادثة المشرف الشخصية، إذا أردت إرسال تنبيهات له أيضًا.
- `GEMINI_API_KEY`: مفتاح Gemini؛ اختياري، لكن يساعد على فهم الأسئلة المصاغة بطرق مختلفة.

بعد إضافة الأسرار، افتح Actions وشغّل workflow يدويًا من Run workflow. تأكد أن البوت موجود في المجموعة والقناة، وأنه يستطيع إرسال الرسائل ونسخ منشورات القناة.

## حدود مهمة
البوت يستطيع نسخ المنشورات المعرّفة حاليًا داخل `VIDEOS` فقط. لا يستطيع بوت Telegram تحميل تاريخ القناة القديم كاملًا تلقائيًا. لاستعمال كل منشورات القناة، يلزم تصدير منشورات القناة من Telegram Desktop ثم إضافة آلية استيراد/فهرسة لهذا التصدير. منشورات القناة الجديدة التي تصل للبوت تُسجّل في سجل التشغيل فقط في النسخة الحالية ولا تُحفظ في قاعدة بيانات دائمة.

إذا لم تتطابق صيغة السؤال مع الكلمات المعروفة، يحاول Gemini اختيار موضوع من المواضيع المدعومة. إذا تعذّر تحديد موضوع، يُحوّل السؤال للمشرفين بدل تخمين الإجابة. Gemini اختياري؛ من دونه تبقى المطابقة النصية شغّالة.

## البحث عن مواصفات المنتجات (جديد)
عندما يرسل عضو صورة منتج مع سؤال (أو سؤالًا نصيًا عن مواصفات منتج فيه رقم الموديل)، يعمل `product_search.py`:

1. Gemini Vision يقرأ الاسم والماركة والموديل والمرجع **الظاهرة فقط** (يحتاج `GEMINI_API_KEY`).
2. البحث في `products_catalog.json` (كتالوج Mayna الاختياري؛ فارغ افتراضيًا، المشروع لا يحتوي على قاعدة منتجات).
3. إن لم يوجد: بحث Gemini مع Google Search، ولا تُقبل النتيجة إلا إذا كان الموديل مطابقًا وفيها روابط مصادر.
4. المعلومة "مؤكدة" فقط إذا جاءت من الكتالوج أو من مصدر ويب للموديل نفسه؛ وغير ذلك يُعرض تحت "ما تحققناش منها" أو لا يُعرض.
5. إذا لم يتضح الموديل: يطلب البوت صورة الملصق أو رقم الموديل. وإذا فشل Gemini أو البحث أو لم توجد معلومات موثوقة: يُرسل السؤال والصورة إلى `ADMIN_CHAT_ID`.

صورة بلا سؤال لا يرد عليها البوت. صيغة الكتالوج: `{"products": [{"name": "...", "model": "...", "aliases": [], "url": "...", "specs": {"القوة": "1400 W"}}]}`.
متغيرات اختيارية: `PRODUCT_GEMINI_MODEL`, `PRODUCT_CATALOG_FILE`.


## ميزة تتبع DHD (تجريبية)

عند إرسال رقم تتبع واضح وحده في مجموعة البوت، يحاول البوت قراءة الحالة من نموذج DHD العام. إذا لم يستطع استخراج الحالة (بسبب تغيّر الموقع أو منع الطلبات الآلية)، يوضح ذلك ويرسل رابط التتبع الرسمي بدل اختلاق حالة. هذه الميزة لا تحتاج إلى مفتاح API إضافي، لكنها تحتاج اتصال GitHub Actions بموقع DHD. اختبرها برقم شحنة معروف بعد نشر التحديث؛ لا تعتبرها مضمونة قبل نجاح الاختبار الفعلي.
